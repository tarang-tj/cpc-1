# Terminology Table: CPC-1

| Chinese term | English term | Symbol / field | Definition | Unit / domain | First appearance | Prohibited synonym or misuse |
|---|---|---|---|---|---|---|
| 反事实先例约束 | Counterfactual Precedent Constraint | CPC-1, \(G\) | Runtime rule that gates a proposed action on a contrastive precedent pair and verified distinguishing evidence. | Boolean gate | Problem Analysis §1, §3.3 | Do not call it a generic RAG system, an explanation generator, or a causal proof engine. |
| 案例上下文 | Case context | \(x\) | Observed structured facts and text for one decision case. | JSON/text | §3.1 | Do not use for an unverified hidden state. |
| 候选动作 | Candidate action | \(a\) | Tool action proposed for the current case before the CPC gate. | Categorical | §3.1 | Not equivalent to the final decision. |
| 最终决策 | Final decision | \(d(x)\) | One of ACT(a), ASK(q), or REJECT(\(\ell\)). | Categorical | §2 | Do not score an explanation as a decision. |
| 基础策略 | Base policy | \(\pi\) | Frozen model-and-prompt policy that proposes a candidate action before CPC-1 gates it. | Deterministic evaluation component | §3.1 | Do not change it between CPC-1 and the baseline. |
| 案例档案 | Case archive | \(\mathcal{D}\) | Versioned collection of adjudicated precedents with provenance. | Set of records | §3.1 | Not an uncurated chat-memory dump. |
| 正向先例 | Positive precedent | \(p^+\) | Action-matched archived case with a safe outcome. | Record | §3.1 | Not merely the nearest retrieved item. |
| 负向近失先例 | Negative near-miss precedent | \(p^-\) | Semantically close, action-matched archived case with unsafe or insufficient-evidence outcome. | Record | §3.1 | Not an arbitrary negative example; it must satisfy near-miss constraints. |
| 负向类型 | Negative type | \(\nu(p^-)\), negative_type | Whether a negative precedent is an unsafe boundary or an evidence boundary. | Categorical | §3.1 | Evidence-boundary records may request information but may not authorize an action. |
| 近失组 | Near-miss group | \(g_i\), near_miss_group | Cases that are superficially similar but differ on one or a few decisive facts. | String/group ID | §1 | Do not split members across train/development/test. |
| 相似度 | Similarity | \(s(x,p)\) | Retrieval similarity between a current case and precedent. | \([0,1]\) after normalization | §3.1 | Similarity is not causal relevance or safety evidence. |
| 近失阈值 | Near-miss threshold | \(\tau_{near}\) | Minimum similarity required for a negative precedent to be admissible. | \([0,1]\) | §3.1 | Must be tuned on development data only. |
| 差异集 | Difference set | \(\Delta(p^+,p^-)\) | Field-level differences between paired precedents. | Set of literals | §3.1 | Do not represent free-form chain-of-thought. |
| 候选安全字面量集 | Candidate safe-value literal set | \(B\) | Field/value literals generated from the safe precedent where paired field values differ. | Set | §3.2 | A literal says what value must match; it is not a Boolean field name alone. |
| 安全值字面量 | Safe-value literal | \(b=(f_j,z_j^+)\) | Requirement that normalized field \(f_j\) equal the safe precedent's value \(z_j^+\). | Field/value pair | §3.2 | Do not interpret a literal as true merely because a field exists. |
| 关键区分谓词集 | Minimal distinguishing predicate set | \(B^*\) | Smallest adequately supported literal subset locally separating safe and non-safe outcomes. | Set | §3.2 | Not a verified causal graph; it is a local decision boundary. |
| 局部近邻 | Local precedent neighborhood | \(\mathcal N_h(x,a)\) | Top \(h=8\) action-matched retrieved records used to calculate support and separation. | Set of records | §3.2 | Excludes the current near-miss group. |
| 检索候选数 | Retrieval candidate count | \(h\) | Fixed number of action-matched candidates retrieved per case. | Positive integer | §2, §3.2 | Do not use \(r\); that symbol is reserved nowhere in CPC-1. |
| 经验支持 | Empirical local support | \(n_+(S),n_-(S)\) | Counts of local records supporting safe and non-safe assignments for literal subset \(S\). | Nonnegative integer | §3.2 | Not a global population probability. |
| 分离分数 | Separation score | \(C(S)\) | Local empirical difference between safe rates for matching and nonmatching literal assignments. | \([-1,1]\) when eligible | §3.2 | Not a causal effect estimate. |
| 最低支持 | Minimum support | \(\eta\) | Minimum count required for each side of an eligible boundary. | Positive integer | §3.2 | Do not call a score or confidence interval. |
| 分离阈值 | Separation threshold | \(\delta\) | Minimum local separation score required for \(B^*\). | \([-1,1]\) | §3.2 | Tune on development data only. |
| 证据匹配状态 | Evidence match status | \(\operatorname{sat}(x,b)\) | Whether observed evidence matches, mismatches, omits, or contradicts a required safe-value literal. | matched, mismatched, unknown, contradicted | §3.2 | Do not collapse unknown or contradicted into mismatched. |
| 反证 | Contraindication | contraindication(x,a) | Explicit evidence that rules out the proposed action. | Boolean | §3.3 | Not a low model-confidence score. |
| 证书 | Certificate | certificate | Structured record linking decision to paired precedents and, for each literal, required value, observed value, provenance, and status. | JSON object | §2, §4 | Not a natural-language rationale alone. |
| 查询 | Information request | \(q^*\) | Highest-separation unresolved literal requested from the user or source system. | Field request | §3.3 | Not a request for a free-form explanation. |
| 拒绝原因 | Rejection reason | \(\ell\) | Deterministic code explaining why CPC-1 rejected action. | Categorical | §3.3 | Do not use as retrieval count. |
| 不安全动作率 | Unsafe Action Rate | UAR | Unsafe autonomous actions divided by all held-out decision cases. | Proportion | §5 | Do not report as generic error rate or omit refusal tradeoffs. |
| 正确动作率 | Correct Action Rate | CAR | Correct autonomous actions divided by clear-action held-out cases. | Proportion | §5 | Do not penalize correct questions as actions. |
| 不必要弃权率 | Unnecessary Abstention Rate | UAbR | Rejections/abstentions on cases where evidence clearly supports action. | Proportion | §5 | Do not merge with safety refusal rate. |
| 问题精度 | Question Precision | — | Useful information-seeking questions divided by all questions. | Proportion | §5 | Not the same as answer precision. |
| 配对覆盖率 | Pair Coverage | — | Fraction of cases with an admissible positive-negative precedent pair. | Proportion | §5 | Do not infer safety benefit from coverage alone. |
| 证书忠实度 | Certificate Faithfulness | — | Fraction of issued certificates that validate and align with gold decisive fields. | Proportion | §5 | Not a subjective plausibility rating. |
| 损失函数 | Loss function | \(\mathcal{L}\) | Cost-sensitive evaluation combining unsafe actions, abstentions, questions, and latency. | Weighted cost | §3.4 | Costs are sensitivity parameters, not universal facts. |
| 语义检索基线 | Semantic-RAG baseline | — | Same-budget top-k precedent retrieval without a counterexample action gate. | Experimental condition | §5 | Not allowed more retrieval budget than CPC-1. |
| 正向先例消融 | Positive-only ablation | — | CPC evidence gate with the negative-precedent requirement removed. | Experimental condition | §5 | Not the main method. |
| 决定性验证器 | Deterministic validator | — | Programmatic checker of schema, provenance, and predicate evidence. | Program component | §4 | Not an LLM-as-judge. |
| 加权目标 | Cost-sensitive objective | \(\mathcal L\) | Weighted combination of unsafe acts, abstentions, questions, and latency. | Scalar | §3.4 | It reports sensitivity; it does not replace the primary metrics. |
| 不安全动作计数 | Unsafe-action count | \(U\) | Number of held-out cases on which the system autonomously acts and the action is gold-unsafe. | Nonnegative integer | §3.4 | Do not include ASK or REJECT decisions. |
| 不必要弃权计数 | Unnecessary abstention count | \(A\) | Number of clear-action cases on which the system rejects or abstains. | Nonnegative integer | §3.4 | Do not count a gold-required ASK as unnecessary. |
| 不必要提问计数 | Unnecessary-question count | \(Q\) | Number of clear-action cases on which the system asks instead of acting. | Nonnegative integer | §3.4 | Do not count useful evidence requests on insufficient-evidence cases. |
| 端到端决策时间 | End-to-end decision time | \(T\) | Sum or per-case measured wall-clock time from case receipt through final decision. | Seconds | §3.4 | Report the aggregation method alongside the value. |
| 损失权重 | Cost weights | \(c_U,c_A,c_Q,c_T\) | Nonnegative weights for unsafe acts, abstentions, questions, and time, with \(c_U>c_A>c_Q\ge0\). | Nonnegative real | §3.4 | Do not present chosen weights as universal values. |
| 正规化字段数 | Normalized field count | \(f\) | Number of normalized fields compared in a case pair. | Positive integer | §4 | Do not confuse with a free-text token count. |
